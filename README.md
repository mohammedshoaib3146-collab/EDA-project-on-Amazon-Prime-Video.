## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on an Amazon Prime Video dataset to understand its content library and uncover meaningful patterns in movies and TV shows.

Using Python, Pandas, NumPy, Matplotlib, and Seaborn, the project explores content distribution, release trends, genres, production countries, IMDb ratings, and cast and crew information.

The objective is to transform raw data into meaningful insights through data cleaning, analysis, and visualization.

## 🎯 Project Objectives

- Analyze the distribution of movies and TV shows.
- Identify popular genres and major content-producing countries.
- Explore content release trends over time.
- Examine IMDb ratings and available rating metrics.
- Identify directors and actors associated with the largest number of titles.
- Generate insights that can support data-driven content analysis.

## 📂 Dataset Description

The project uses two CSV datasets:

| Dataset | Description |
|---|---|
| `titles.csv` | Information about titles, content type, release year, genres, runtime, and available ratings. |
| `credits.csv` | Information about actors, directors, roles, and their associated titles. |

*The actual columns and available information depend on the dataset version.*
